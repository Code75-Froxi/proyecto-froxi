\# Proyecto Froxi



\## Descripción

Froxi es un videojuego educativo desarrollado en Unity 2D que busca promover el aprendizaje sobre la alimentación saludable entre estudiantes de nivel medio superior.



\## Objetivo

Favorecer el reconocimiento de alimentos saludables y reforzar conocimientos sobre los hábitos alimenticios mediante preguntas y mecánicas interactivas.



\## Mecánicas principales

\- Froxi recorre diferentes niveles y recoge frutas y verduras.

\- La comida chatarra aparece como enemiga.

\- Al entrar en contacto con un enemigo, aparece una pregunta sobre alimentación saludable.

\- Las respuestas correctas permiten obtener puntos.

\- Las respuestas incorrectas hacen que Froxi pierda una vida.
